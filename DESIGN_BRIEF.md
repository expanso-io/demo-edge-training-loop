# Local learning board

Use the existing demo-kit tokens, topology board, event feed and adjacent
before/after answer pattern. Warm paper fits transcript review; blue names
Expanso control and teal marks accepted results. Amber means human attention.
Keep monospace for identifiers and measured data only. Use the vendored
Barlow Condensed face for labels and conversation text.

The customer boundary contains both sites and the training node. The review
form carries the uncertain decision. The gate carries the release decision.
The Cloud label reports verified control-plane state; it is never a button.

Build the board in `showcase/` using the existing vocabulary, then port it to
`dashboard/`. One direction is sufficient because the house design already
settles the layout and token choices. On narrow screens, preserve reading
order: site collection, teacher review, gate, site answers, event history.
