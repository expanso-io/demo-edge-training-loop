# Train where the conversations happen

A voice AI platform that runs on the customer's own infrastructure can improve
its small language model without sending conversations to an outside model.
This demo collects text conversations at two sites, grades them with a local
teacher, asks a person to review uncertain corrections, trains a LoRA adapter,
and releases it only when it beats the current model on held-out requests.

The presenter lives at **http://localhost:8024**. Expanso Cloud manages five
pipelines; all conversation bodies, model inference and training stay on this
Mac. Cloud receives job metadata, operational logs and metrics. The logs contain
record identifiers and processing status, not conversation bodies.

## Run on this Mac

Prerequisites: Docker Desktop, Ollama with `mistral-small:24b`, Expanso Edge and
CLI, `uv`, Node/npm and `just`. The student weights are cached under `.models/`.
The pinned container downloads dependencies when built; inference and training
use local weights. The owner-only `.env` supplies this project's Cloud endpoint,
API key and bootstrap token. Never use a global CLI profile.

From this folder:

```sh
npm ci
just check
just up
just deploy
just record-check
```

`up` starts Docker if needed, builds the local image, starts the two site
services, training service, three Edge agents and presenter. `deploy` explicitly
deploys the five selector-bound Cloud jobs and waits for Running. The presenter
can approve corrections but cannot start, stop or deploy Cloud jobs.

To make new conversations, run `just produce`. Read each correction on the
board and approve or fix it. See [RECORDING_SCRIPT.md](RECORDING_SCRIPT.md) for
the rejected first batch and the complete take.

```sh
just rollback
just release-again
just down
```

Rollback in this first-release demo returns both sites to the original base
model. Watch site receipts before re-releasing. `down` stops only the five named
Cloud jobs and project-owned processes/containers. It stops Docker only if this
project started it and no other containers are running. Ollama's pre-existing
server is retained; `ollama stop mistral-small:24b` unloads the teacher when done.

For a fresh take, stop first, then preserve the prior run and reset:

```sh
just down
just reset
just up
just deploy
```

`reset` archives state and adapters under `.runtime/archive/`; it preserves model
weights, credentials and node identities. It refuses while demo services run.

## What was proved

The first verified run rejected an undersized batch, then trained on 17 approved
records in 159.2 seconds. The eight held-out policy checks improved from 0/8 to
8/8. Both sites received the actual adapter through Expanso, acknowledged local
inference, rolled back to base, and accepted the adapter again.

These are measurements of one small, fixed policy exercise. The rubric checks
for the required reference and a short list of forbidden claims. It does not
measure general quality, voice quality, or production safety. Teacher confidence
is self-reported, not calibrated. See [docs/RESEARCH.md](docs/RESEARCH.md) and the
JSON evidence files for the exact scope.

Cloud console Logs and Monitoring need a signed-in manual check before the
take; the installed CLI log stream fails its WebSocket handshake. This accepted
preflight warning is detailed in [RECORDING_PREFLIGHT.md](RECORDING_PREFLIGHT.md).

## Implementation map

- `pipelines/`: transcript collection, teacher call, scheduled training trigger,
  and canary-first adapter delivery; generated by `scripts/write_pipelines.py`.
- `scripts/service.py`, `learning.py`, `gate.py`: local services, pinned CPU LoRA
  training and held-out gate. HTTP model calls have single-flight admission.
- `scripts/corpus.py`: authored requests, separate held-out requests and rubric.
- `scripts/store.py`: SQLite event journal, review decisions and site receipts.
- `scripts/runtime.py`: explicit operator lifecycle and archive/reset commands.
- `dashboard/`: local presenter, fresh read-only Cloud status and human review.

Local operational state and secrets are gitignored. There is no remote repo.
